# Hotel Luxo Estilizado
Aplicativo criado em .NET MAUI para criar uma simulação de reserva de hotel. 
O projeto faz uso de componentes gráficos como Image, Frame, Stepper, DatePicker e Picker, 
e inclui navegação entre telas.

## Características 
Reserva de acomodações 
Seleção de datas 
Escolha do tipo de quarto 
Tela de serviços 
Tela sobre o projeto 
Interface sob medida
